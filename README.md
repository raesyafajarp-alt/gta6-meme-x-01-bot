A GTA 6 meme about waiting 13 years for the game — while the agent already got paid. The picture is a Vice City sunset scene with make.fun's ghost mascot riding along, captioned "WAITED 13 YEARS FOR GTA 6 / MY AGENT ALREADY GOT PAID", posted on X with the bounty link, @makefunai and the entry's play code. The post itself is the entry: the house reads it from X and an AI judge compares it against the other posts.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `POST.json` (the post's address on X) into `out/POST.json`, refusing to run while it still holds the starter's placeholder.
